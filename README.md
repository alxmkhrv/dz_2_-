
# Примитивная база данных

## Описание проекта

Примитивная база данных — программа, которая реализует консольную систему управления таблицами.

Программа позволяет:
- Создавать таблицы с заданными столбцами и типами данных.
- Просматривать список существующих таблиц.
- Удалять таблицы.
- Сохранять структуру таблиц в JSON-файле.

Поддерживаемые типы данных: `int`, `str`, `bool`.

Проект разработан на Python 3.12 с использованием пакетного менеджера `uv`.

## Установка и запуск

Для работы с проектом необходимы Python 3.12 и пакетный менеджер `uv`.

### Сборка пакета

В корневой директории проекта выполните:

```bash
uv build
```

После сборки в директории `dist/` появятся файлы `.whl` и `.tar.gz`.

### Установка пакета

Установите собранный пакет командой:

```bash
uv tool install dist/primitive_db-0.1.0-py3-none-any.whl
```

Если пакет уже установлен, используйте `--force` для переустановки.

### Запуск базы данных

После установки запустите программу командой:

```bash
database
```

Для запуска непосредственно из проекта можно использовать:

```bash
uv run database
```

## Управление таблицами

После запуска программы доступны пять команд:

| Команда | Описание |
|---|---|
| `create_table <имя_таблицы> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать список всех таблиц |
| `drop_table <имя_таблицы>` | Удалить таблицу |
| `help` | Показать справочную информацию |
| `exit` | Завершить программу |

Поддерживаемые типы данных: `int`, `str`, `bool`.

При создании таблицы автоматически добавляется столбец `ID:int`, если он не указан пользователем.

Метаданные таблиц сохраняются в файле `db_meta.json`.

### Пример использования

Создание таблицы:

```text
Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
```

Просмотр существующих таблиц:

```text
Введите команду: list_tables
- users
```

Попытка повторного создания:

```text
Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.
```

Удаление таблицы:

```text
Введите команду: drop_table users
Таблица "users" успешно удалена.
```

Обработка неизвестной команды:

```text
Введите команду: hello
Функции hello нет. Попробуйте снова.
```

Завершение работы:

```text
Введите команду: exit
```
